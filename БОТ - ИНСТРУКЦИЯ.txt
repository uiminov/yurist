TELEGRAM-БОТ ДЛЯ ФОРМИРОВАНИЯ СУДЕБНЫХ ЗАЯВЛЕНИЙ
=================================================
(интерфейс бота — на узбекском языке)

КАК ЗАПУСТИТЬ
-------------
1. Установите Python: https://www.python.org/downloads/
   ВАЖНО: галочка "Add Python to PATH" при установке.
2. Дважды кликните BOT.bat — библиотеки поставятся сами.
3. В консоли появится: "BOT ISHGA TUSHDI: @имя_бота".
4. Откройте бота в Telegram и нажмите /start.

Бот работает, пока открыто окно BOT.bat. Закрыли окно — бот остановился.
Токен уже вписан в bot.py (строка TOKEN).

КАК РАБОТАЕТ (то, что видит пользователь)
----------------------------------------
1. /start → бот просит прислать список:
   "Qarzdorlar ro'yxati yozilgan Excel faylni (.xlsx) yuboring."
2. Пользователь отправляет .xlsx — ОДИН раз. Всё делается за один проход:
   проверка списка, формирование заявлений, архив, реестр, отчёт.
   Пока идёт работа, бот держит одно сообщение со счётчиком:

       Arizalar tayyorlanmoqda
       ████████░░░░░░  57%
       23 / 40 ta ariza
       IVANOV ALISHER
       Taxminan 12 soniya qoldi

   Дальше счётчик показывает упаковку архива и отправку.
3. Бот формирует по одному заявлению на каждого должника В PDF и присылает:
   • 1 должник  → сразу .pdf
   • несколько  → .zip архив (крупные списки бьются на части по 45 МБ)
   PDF делает установленный на компьютере Microsoft Word — выглядит один
   в один с шаблоном (шапка, логотип, шрифты). ~0.5 с на заявление,
   224 заявления — около 2 минут. Word запускается невидимо и сам
   закрывается; ваши открытые документы Word он не трогает.
   Если Word не запустился — заявления придут в .docx, и первой строкой
   отчёта будет предупреждение. Вернуть Word-формат насовсем:
   в generate_sud.py  OUTPUT_FORMAT = "docx".
4. Следом приходит РЕЕСТР — таблица .xlsx: строка на каждого должника
   (ID, ФИО, ЖШШИР, паспорт, телефон, адрес, все суммы, имя файла заявления)
   и строка ЖАМИ с итогами. Суммы — числа, можно сразу считать в Excel.
   Если были предупреждения, в реестре появляется второй лист с их списком.
5. В конце — отчёт: сколько должников, общая сумма задолженности,
   общая сумма взыскания, и предупреждения, если что-то не сошлось.

КОМАНДЫ БОТА
------------
  /start        — начать
  /namuna       — прислать namuna.xlsx с правильными заголовками
  /shablon      — выбрать шаблон заявления (кнопками)
  /tekshirish   — ещё раз разобрать последний список, без формирования
  /oxirgi       — прислать последний результат ещё раз
  /sozlamalar   — показать текущие настройки
  /sud 100000   — изменить сумму суд/ундирув харажати
  /pochta 22000 — изменить сумму почта харажати (по умолчанию 22 000;
                  колонка "почта харажати" в Excel не учитывается)
  /id           — узнать свой Telegram ID
  /yordam       — справка

КНОПКИ ПОД ПОЛЕМ ВВОДА
----------------------
  Namuna Excel  — образец файла           Shablon       — выбрать шаблон
  Tekshirish    — разбор прошлого списка  Oxirgi natija — прислать прошлый результат
  Sozlamalar    — настройки               Yordam        — справка

ПРОВЕРКА (Tekshirish)
---------------------
Отдельно включать проверку НЕ нужно: каждый присланный список проверяется
автоматически, и предупреждения приходят вместе с готовыми заявлениями.
Файл отправляется один раз.

Кнопка "Tekshirish" нужна для другого: она заново разбирает ПОСЛЕДНИЙ
присланный список и показывает сводку — количество, суммы, дубликаты,
пустые ячейки — плюс реестр. Документы при этом не формируются заново,
готовые лежат в "Oxirgi natija".

ЧТО БОТ ПРОВЕРЯЕТ САМ
---------------------
• ДУБЛИКАТЫ: два должника с одинаковым ЖШШИР (ПИНФЛ) или одинаковым
  ID заказа — в отчёте будет строка вида
  "16-qator, ИВАНОВ И.И.: ЖШШИР 13-qator bilan bir xil — takror qarzdor".
  Номера — это номера строк в вашем Excel, так их легко найти.
• незаполненные ячейки (ID заказа, сумма заказа, дата заказа);
• колонка "жами карздорликк" не сошлась с расчётом;
• метки шаблона, которые не удалось заменить.
Бот не удаляет такие строки — документы формируются, но вы предупреждены.

ПОСЛЕДНИЙ РЕЗУЛЬТАТ (Oxirgi natija)
-----------------------------------
Бот помнит последний отправленный архив и реестр для каждого чата и может
прислать их снова по кнопке или командой /oxirgi — список заново гонять
не нужно. Файлы хранятся на серверах Telegram, не на вашем компьютере.

ДОПОЛНИТЕЛЬНЫЕ ВОЗМОЖНОСТИ
--------------------------
• Отправьте боту .docx — он сохранит его как новый шаблон и сразу выберет.
  То есть шаблон можно менять прямо из Telegram, не заходя на компьютер.
• Бот сам определяет тип шаблона (новый со скобками / старый заглавными).
• Настройки (шаблон, суммы) запоминаются отдельно для каждого чата
  в файле bot_sozlamalari.json.
• Все действия пишутся в bot.log.
• Дубликаты имён файлов не перетираются — добавляется (2), (3)...

ОГРАНИЧЕНИЕ ДОСТУПА (рекомендую включить)
-----------------------------------------
Пока бот открыт для всех, кто его найдёт. Чтобы закрыть:
1. Напишите боту /id — получите свой номер.
2. Откройте bot.py, найдите строку:
       RUXSAT_ETILGANLAR = []
   и впишите номера через запятую:
       RUXSAT_ETILGANLAR = [123456789, 987654321]
3. Перезапустите BOT.bat.
Остальные получат отказ. Это важно — в заявлениях есть паспорта и ПИНФЛ.

ТОКЕН
-----
Токен = пароль от бота. Не выкладывайте bot.py в открытый доступ.
Если утёк — @BotFather → /revoke → новый токен вписать в bot.py.
