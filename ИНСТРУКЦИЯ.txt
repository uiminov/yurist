АВТОМАТИЧЕСКОЕ ФОРМИРОВАНИЕ СУДЕБНЫХ ЗАЯВЛЕНИЙ
===============================================

ЧТО В ПАПКЕ
-----------
  Ариза Олча палатага.docx — шаблон заявления (новый)
  Судга ариза.docx         — старый шаблон (тоже поддерживается)
  Книга10.xlsx             — список должников (сюда вносите данные)
  generate_sud.py          — сам скрипт
  ЗАПУСК.bat               — запуск в один клик
  Готовые заявления\       — сюда складываются готовые документы

ПЕРВЫЙ ЗАПУСК (один раз)
------------------------
1. Установите Python: https://www.python.org/downloads/
   ВАЖНО: при установке поставьте галочку "Add Python to PATH".
2. Всё. Библиотеки .bat поставит сам.

КАК ПОЛЬЗОВАТЬСЯ (каждый раз)
-----------------------------
1. Откройте Книга10.xlsx, впишите строки должников.
2. Закройте Excel (иначе файл будет заблокирован).
3. Дважды кликните ЗАПУСК.bat.
4. Заберите документы из папки "Готовые заявления" — они в PDF.

Имя файла: ФИО + дата заказа + "суд карори" .pdf
PDF делает установленный Microsoft Word (нужна библиотека pywin32 —
ЗАПУСК.bat ставит её сам). Если Word недоступен, останутся .docx.

ДВА ШАБЛОНА
-----------
Скрипт сам определяет, какой шаблон перед ним:
  • новый  — метки в круглых скобках:  (фиш), (адрес), (заказ ид)...
  • старый — метки заглавными буквами: ЗАКАЗ ИД, ОСТАТОК ДОЛГ...
В настройках указано, какой файл брать:
  EXCEL_FILE    = "Книга10.xlsx"
  TEMPLATE_FILE = "Ариза Олча палатага.docx"
Чтобы переключиться на старый — поменяйте эти две строки.

КОЛОНКИ EXCEL (новый шаблон)
----------------------------
  ID заказа           -> номер договора ("...-сонли")
  ФИО                 -> Қарздор в шапке и по тексту
  Остаток долга       -> основной долг
  Сумма заказа        -> общая сумма по договору
  дата заказа         -> дата акцепта
  дата истеченя срок  -> дата окончания графика платежей
  ПИНФЛ               -> ЖШШИР + из него берётся ДАТА РОЖДЕНИЯ ("й.т.")
  Паспорт серия       -> серия и номер паспорта
  Телефон             -> телефон должника
  Адресс              -> адрес должника
  суд харажати        -> ундирув харажатлари (обычно 100 000)
  почта харажати      -> НЕ используется: почта всегда POCHTA_HAQI (22 000),
                         в старых списках там 20 600 — это игнорируется
  жами карздорликк    -> контрольная сумма (см. ниже)

Порядок колонок и регистр не важны — скрипт ищет их по названию.
Обязательные: ФИО и Остаток долга. Пустые строки пропускаются.

ЧТО СЧИТАЕТ СКРИПТ САМ
----------------------
  Дата рождения      = из ПИНФЛ (цифры 2-7 = ДДММГГ, 1-я цифра = век)
  Жами қарздорлик    = Остаток долга + суд харажати
  Ундириш суммаси    = Остаток долга + суд харажати + 22 000 (почта)

Колонка "жами карздорликк" из Excel используется только как ПРОВЕРКА:
если она не совпадает с расчётом, скрипт напишет предупреждение,
а в документ поставит свой расчёт.

НАСТРОЙКИ (файл generate_sud.py, верхний блок)
---------------------------------------------
  EXCEL_FILE / TEMPLATE_FILE — какие файлы брать
  XIZMAT_HAQI / POCHTA_HAQI  — значения по умолчанию, если колонок нет
  FILE_NAME_TEMPLATE         — шаблон имени файла
  OUTPUT_FORMAT              — "pdf" (по умолчанию) или "docx"
  OUTPUT_DIR                 — папка выгрузки
  MONEY_DECIMALS             — "auto" копейки только если есть,
                               "never" округлять до сўм, "always" всегда .00
  REMOVE_HIGHLIGHT           — убирать жёлтую подсветку
  COLUMNS                    — синонимы названий колонок

ЕСЛИ МЕНЯЕТЕ ШАБЛОН WORD
------------------------
Метки нового шаблона (оставляйте их как есть):
  MAMAYUSUPOVA FIRDAVSXON MAXSUDOVNA (фиш)   — образец ФИО, ищется по "(фиш)"
  ... дом 17 (адрес)                          — вся строка до "(адрес)"
  31.10.1989 й.т.                             — дата рождения
  AC2197627(п.сериа)
  43110894320043 (пнфл)
  998905880214(тел)
  23.08.2024(дата заказа)
  01.09.2025(Срок истечение договора)
  774376(заказ ид)
  12 936 000Сумма заказа
  1 155 214(Остаток основного долга)
  100 000 сўм ундирув харажатлари
  20 600.00 сўм почта харажатини
  1 305 214( остаток долг + 100 000 )
  1 325 214( остаток долг + 100 000 + почта )

Формат текста (шрифт, жирность, отступы, шапка с логотипом) сохраняется.
После каждого документа скрипт проверяет, не осталось ли незаменённых
меток, и пишет предупреждение в консоли.

ЧАСТЫЕ ОШИБКИ
-------------
"Python не найден"          — не поставили галочку "Add Python to PATH"
"В папке несколько файлов"  — укажите нужный в EXCEL_FILE / TEMPLATE_FILE
Файл не сохраняется         — закройте Excel/Word с этими файлами
